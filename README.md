## Висновки

- За результатами обчислень маємо, що найбільшу збіжність мав метод Сімпсона, оскільки він має найменшу n серед усіх методів при обох значень ε.
- На другому місці найбільшу збіжність має метод трапецій, хоча воно має найбільшу n, але по точності збігу при другому ε, цей метод вже обганяв точність з методом прямокутників, і відповідно чим меншу ми візьмемо ε, тим краще буде працювати цей метод.
- Найгіршу збіжність очевидно що має метод прямокутників, за загальним принципом методу, цей висновок варто було очікувати, він є доведеним за минулою тезою + за великими значеннями n.
